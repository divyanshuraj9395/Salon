# Glow & Go — Editable Salon Website

Files:
- `index.html` — all page content and sections
- `style.css` — colors, spacing, responsive layout, typography
- `script.js` — service filters, mobile menu, booking form demo
- `assets/design-reference.png` — supplied design reference

## Edit
Open the folder in VS Code. Change text directly in `index.html`.
Change colors in `style.css`. Replace each placeholder block with an `<img>` element and put your images in `assets/`.

## Run
Double-click `index.html`, or use VS Code Live Server.

The booking form is front-end only. It can later be connected to WhatsApp, Formspree, PHP, Firebase, or another backend.
